# VANTAGE — THE MASTER MEGA PROMPT
## Product Vision, Intelligence Architecture & Engineering Constitution

*(Archived Specification Document)*

### Core Product Mandate
Vantage is an intelligence terminal for the internet's emerging trends, communities, ideas, products, and digital culture.
It transforms raw multi-source data into verifiable signals, temporal patterns, entity relationship graphs, and calibrated probabilistic predictions.

### Key Tenets
1. Multimodal Temporal Intelligence: Text, code, visual embeddings, time-series, and graph topologies treated as equal first-class citizens.
2. Rigorous ML Engineering: No LLM hallucination for statistical tasks. Time-series, clustering, and graph algorithms handle metrics; LLMs synthesize research reports and explain evidence.
3. Traceable Provenance: Every claim links to verified historical observations.
4. Human-Grade Engineering: Complete, tested, production-ready code with automated tests and clear APIs.
